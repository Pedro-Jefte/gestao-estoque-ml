# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

- Frontend: React + Vite + Vanilla CSS
- Backend: Node.js + Express
- Database: Supabase (PostgreSQL) + Prisma

## Users

O dono da borracharia (Borracheiro) e funcionários que precisam gerenciar o estoque local.

## Product Purpose

Uma plataforma (Dashboard Web) para controle de estoque de pneus. O principal objetivo é automatizar a baixa no estoque local assim que uma venda for realizada no Mercado Livre (via webhook). O sistema deve passar uma imagem "Premium", moderna e confiável.

## Positioning

Um sistema de nicho (focado em borracharias/autopeças) que elimina a dor de cabeça de atualizar o estoque manualmente no Mercado Livre e localmente, evitando vendas duplicadas.

## Operating Context

O sistema será acessado predominantemente pelo navegador em um computador na própria borracharia (no balcão de atendimento) ou pelo celular para consultas rápidas de disponibilidade.

## Capabilities and Constraints

- **Integração:** Autenticação via Mercado Livre e recebimento de Webhooks de vendas.
- **Visual:** Estilo Dark Mode Premium com detalhes em amarelo (relembrando as cores do Mercado Livre).
- **Sem Aplicativo Nativo:** Apenas PWA/Web responsivo, para facilidade de atualização e acesso sem aprovações de loja.

## Brand Commitments

- **Cores:** Uso sugerido de amarelo estilo "Mercado Livre" (`#ffe600`) para ações conectadas ao ML, fundo escuro predominante (`#0a0a0a`).
- **Nome Provisório:** BorrachaPro.
